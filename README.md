# 灰燼誓約 · Ashen Oath

第一階段可玩原型，手機直立式暗黑奇幻自動戰鬥刷寶 ARPG。

## 目前內容
- 自動尋敵、追擊、近戰攻擊與群怪技能自動施放
- 全螢幕戰場與固定鏡頭構圖
- HP／MP／ES 整合狀態球、底部技能列、下方覆蓋式功能面板
- 三個可切換職業雛形
- 普通／精英／章節首領敵人
- 經驗升級、裝備與輔助寶石掉落、背包與裝備欄
- 每件裝備 0～3 插槽的資料結構
- LocalStorage 自動存檔與 PWA 基礎快取

## 操作
戰鬥全自動。點右下角選單可開啟角色、裝備、背包、技能、天賦與關卡面板。面板開啟時戰鬥不會暫停。

## 開發狀態
此為第一個可玩原型，不代表完整內容已完成。正式角色／怪物美術、寶石實際鑲嵌與效果、完整天賦樹、掉落篩選、Boss 機制、存檔匯入匯出與跨裝置測試仍待後續迭代。
